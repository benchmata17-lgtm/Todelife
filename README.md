# 🚀 Free Scripts Hub (รับเขียนและแจกสคริปต์ฟรีทุกแนว)

ยินดีต้อนรับสู่คลังสคริปต์! ที่นี่รวบรวมและรับเขียนสคริปต์ฟรี 100% ครอบคลุมทุกสายการใช้งาน ไม่ว่าจะเป็นสายเกม (Lua) หรือระบบปฏิบัติการทั่วไป

## 📁 หมวดหมู่ที่เราให้บริการ
- 😈 **สายเกรียน (Troll):** สร้างความปั่นป่วนแบบมีคลาส
- ⚔️ **สายฟาร์ม (Auto-Farm):** ประหยัดเวลาชีวิต ปล่อยบอตทำงานแทน
- 👁️ **สายดึงข้อมูล (ESP):** ทะลุปรุโปร่ง รู้ทุกความเคลื่อนไหว
- ⚡ **สายบูสต์ (FPS Boost):** รีดประสิทธิภาพเครื่องและตัวเกมให้ลื่นที่สุด
- 🛠️ **สายสร้างแมพ (Builder):** เครื่องมือทุ่นแรงสำหรับนักพัฒนา

## 📝 วิธีขอให้ช่วยเขียนสคริปต์ (ฟรี)
คลิกที่แท็บ **[Issues](../../issues)** ด้านบน แล้วกดปุ่ม **New Issue** จากนั้นตั้งคำขอโดยใช้รูปแบบนี้เท่านั้น:

* **หัวข้อ:** (เช่น ขอสคริปต์ลบเงาและพื้นผิว)
* **ตัวรัน:** (เช่น Delta, Synapse, รันใน Studio)
* **ภาษา:** (เช่น Lua, Python, AutoHotkey)
* **ฟังก์ชัน:** (อธิบายสิ่งที่อยากให้สคริปต์ทำงานมาเป็นข้อๆ)
